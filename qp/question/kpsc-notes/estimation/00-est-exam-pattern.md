## Question Style

- **Constants & percentages subject**: >60% of questions ask a NUMBER (a %, a coefficient, an out-turn, a material constant). It rewards a single "constants sheet" (below).
- Numericals are one-multiplication problems: plinth area × rate, bricks = volume × 500, weight = d²/162.
- Very PWD-flavoured: centage, work-charged establishment, provisional sum, muster roll — Kerala PWD account-code terminology.

## Trap Catalogue

| Trap | Resolution |
|------|-----------|
| Salvage vs scrap value | **Salvage = value at end of utility WITHOUT dismantling** ⭐; Scrap/junk = value of MATERIALS after dismantling (~10% cost). Book value = cost − depreciation. |
| Mortgager vs mortgagee | **MortgagOR takes the loan** ⭐ (gives property as security); mortgagee lends. "-or gives, -ee receives" the mortgage. |
| Work-charged 1½–2% vs contingencies 3–5% vs centage 10–15% | Three separate %s — PSC asks all three; don't cross-wire. |
| Prismoidal vs trapezoidal volume | Prismoidal gives SMALLER volume ⭐; prismoidal correction is subtractive. |
| Crank bar extra length | 45°: 0.42D per crank ⭐ (Q47) — but one PSC key said 0.45d (Q52) ⚠; one-side excess = 0.414d ⭐ (Q58). If options have both 0.42 and 0.45, prefer 0.42D for "additional length", 0.414d for "excess of one side". |
| Painting coefficient chaos | See file 06 table — panelled 2¼, fully glazed ½ per side, partly panelled+glazed 2 (both sides). |
| Brick wall in m² vs m³ | m² if thickness ≤ 10 cm (half brick); else m³. |
