# 06 — Painting Coefficients & Painting Measurement

*7 of 65 Qs — bizarrely over-represented in KPSC papers. Learn the one table.*

## 6.1 Why Coefficients?

Doors/windows/grills have complex surfaces. Instead of measuring actual paint area, measure the FLAT OPENING area once and multiply by a coefficient (multiplying factor) per IS 1200 Part 13 / PWD practice.

## 6.2 THE Coefficient Table (⭐ = PSC keys from this bank)

| Item (measured flat) | Coefficient |
|----------------------|-------------|
| **Panelled door (both sides)** | **2¼ (2.25)** ⭐ (Q1) |
| **Partly panelled + partly glazed / gauged doors & windows (both sides)** | **2** ⭐🔁2× (Q19, Q22 — "2 times one surface area for both sides") |
| **Fully glazed / gauged doors (per side)** | **½ (0.5) each side** ⭐ (Q24) (=1 for both sides) |
| Flush door (both sides) | 2.4 🎯 |
| Battened/ledged & braced door (both sides) | 3 🎯 (common exam key) |
| Louvred/venetian door (both sides) | 3 🎯 |
| Corrugated GI sheet (per side) | 1.14 🎯 |
| Corrugated AC sheet | 1.20 🎯 |
| Semi-corrugated AC sheet | 1.10 🎯 |
| Plain steel door (both sides) | 2¼ 🎯 |
| Collapsible gate | 2¼ (each side measured flat ×1.5? — exam key varies) 🎯 |
| Expanded-metal/grill/railings | 1 (each side ½) 🎯 |

⚠️ Q2 anomaly: "Painting CONSTANT of panelled doors" — PSC key **1.30**. This is the OLD PWD constant for ONE side varnishing/painting of panelled door (1.30 per side vs 2.25 both sides ≈ different measurement basis). **Rule: "coefficient … both sides" → 2¼; bare "constant of panelled door" with options 0.8/1/1.3/1.8 → 1.30.**

## 6.3 Painting Measurement Rules — ⭐ asked

- ⭐ **Narrow painting ≤15 cm width/girth (not with similar adjacent work) → RUNNING METRE** (Q18).
- ⭐ **Stiff paint supplied → kg**; ready-mixed paint → litre (Q15 + trap-pair).
- Number of coats specified separately; priming coat measured as painting 🎯.

## 6.4 Painting-Cost Numerical — 🧮 Q4 template

🧮 Q4: room 8×6×3 m, ₹10/m², "interior painting" → **WALLS ONLY**: A = 2(L+B)×H = 2(8+6)×3 = 84 m² → 84×10 = **₹840** ✓
⚠️ PSC's "interior of room" EXCLUDED the ceiling. If stem says "walls and ceiling", add L×B (48) → 132 m².
🎯 Variation: whitewashing cost same template; deduct openings if listed (>0.5 m² rules, file 04).
