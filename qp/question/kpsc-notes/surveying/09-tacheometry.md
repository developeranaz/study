# 09 — Tacheometry

*KPSC weight: ~8 of 203 Qs. Tiny, fixed fact set — 10 minutes of memorization.*

## 9.1 What & When

Tacheometry = angular surveying where horizontal & vertical distances are found **from instrument observations only** (no chaining). Instrument: tacheometer = transit theodolite + **stadia diaphragm** (3 horizontal hairs) + **anallactic lens**.

- ⭐ **Best suited: broken/rough ground where chaining is difficult** (Q93 — "in broken grounds"); also for rivers, steep slopes, reconnaissance, contouring (with plane table = telescopic alidade).
- Accuracy lower than chaining on flat ground (1/300–1/500 typical). 🎯

## 9.2 The Numbers — ⭐ all asked

| Fact | Value |
|------|-------|
| Number of horizontal cross-wires in stadia diaphragm | **3** ⭐ (Q94) |
| **Multiplying constant k = f/i** | **100** ⭐ (Q18) |
| Additive constant C = (f + d) | 0 (anallactic) to ~0.3 m (external focusing) |
| Least count of stadia rod | **5 mm / 0.005 m** ⭐ (Q45) |
| Anallactic lens makes | C = 0, D = ks exactly 🎯 |

## 9.3 Distance Formula — ⭐ asked directly (Q175)

**Line of sight horizontal, staff vertical:**
```
D = (f/i)·s + (f + d)   =   k·s + C
```
s = staff intercept (top hair − bottom hair reading).

- 🧮 Template: k=100, C=0.3, s=1.5 → D = 100×1.5+0.3 = 150.3 m. (🎯 near-certain numerical.)
- Height: central-hair reading used for RL: RL = HI − central reading (horizontal sight).

**Inclined sight, staff vertical (🎯 formulas likely at AE level):**
- Horizontal: D = k·s·cos²θ + C·cosθ
- Vertical: V = k·s·(sin2θ)/2 + C·sinθ

## 9.4 Systems of Tacheometry 🎯

1. **Stadia system** — (a) fixed hair (common), (b) movable hair (subtense).
2. **Tangential system** — 2 vane readings, angles only (no stadia hairs).
3. Range finding.
- Subtense bar (horizontal base, 2 m between targets) with theodolite: D = base/(2·tan(β/2)). 🎯
- Beaman stadia arc: direct H & V without trig tables. 🎯

## 9.5 🎯 High-Probability Variations

- "Stadia interval factor" = f/i = multiplying constant = 100.
- Conditions for anallactic lens (only in external-focusing telescopes).
- Staff held normal vs vertical to line of sight (normal: D = ks·cosθ + …).
- Distance between stadia hairs = i; intercept ∝ distance (principle: isoceles triangle, constant tacheometric angle ≈ 34′ 23″ for k=100).
