## 11.1 Classification of Errors — ⭐ definitions asked

| Type | Nature | Example |
|------|--------|---------|
| **Mistakes (gross errors)** | ⭐ "arise from **inattention, inexperience, carelessness, poor judgment or confusion** of observer" (Q165) | Wrong booking, reading 6 as 9 |
| **Systematic (cumulative) errors** | Same sign & law; accumulate; ∝ L; can be corrected by applying corrections | Chain too long, sag, temperature |
| **Accidental (random/compensating) errors** | Both signs; tend to cancel; ∝ **√L**; follow laws of probability | Marking, reading estimation |

- ⭐ Q109 (repeated trap): "Cumulative errors are proportional to ___" — cumulative ∝ **L**; compensating ∝ **√L**. (PSC's options were garbled → answer 'none of these', but MEMORIZE the L vs √L pair — it WILL return cleanly.)
- Sources of errors: **instrumental, personal, natural** ⭐ (Q37: inaccurate levelling of compass box → PSC said **personal**; ⚠️ some books say instrumental — go with the PSC key when the stem matches Q37 wording).
- Positive error → measured value too large → correction negative.

## 11.3 Probability & Most Probable Value — ⭐ asked

- Most Probable Value (MPV) = arithmetic mean (equal weights).
- ⭐ **Residual error = difference between MPV and observed value** (Q164).
- True error = true value − observed (true value never known). ⚠️ TRAP: residual vs true error.
- 🎯 Likely extensions: probable error of single observation Es = ±0.6745σ; weights inversely ∝ square of probable errors; MPV of weighted observations.
- Discrepancy = difference between two measured values of same quantity (NOT an error itself).

## 11.4 Accuracy vs Precision 🎯 (classic; not yet asked — expect it)

- **Accuracy** = closeness to TRUE value.
- **Precision** = closeness of repeated measurements to EACH OTHER (consistency).
- Can be precise but inaccurate (systematic error present).
