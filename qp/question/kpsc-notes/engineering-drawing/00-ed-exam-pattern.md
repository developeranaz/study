# 00 — How KPSC Asks Engineering Drawing

*Derived from forensic reading of all 55 Engineering Drawing questions (6.9% of paper).*

## The Big Surprise

**~27% of ED marks come from ONE tiny topic: drawing sheet & board sizes.** A-series sheet dimensions, board designations, borders, title block, folding. Memorise one table = 15 questions. Nothing else in the whole exam pays this well per fact.

## Question Style

- Pure memory recall (~90%). Only easy numericals: RF calculations (3×) and sheet-area halving.
- **Same fact re-asked with different wrapping**: A2 size asked 3× (Q5, 33-adjacent, 40), RF of 5 m→25 mm asked 2× verbatim (Q36, Q46), pentagon angles 2× (Q45, 55).
- Sizes/standards dominate: IS codes, mm dimensions, ratios. KPSC loves "trimmed size of Ax".
- The 4 X-questions still show intent: third-angle projection (Q2), T-square use (Q30), section parallel to generator = parabola (Q35), pentagon interior angle 108° (Q45). All four facts are re-askable in clean form — they're in the notes.

## Trap Catalogue

| Trap | Resolution |
|------|-----------|
| **Isometric VIEW vs PROJECTION** | View = drawn with TRUE lengths (no isometric scale) ⭐; projection = 0.815 × true length ⭐. Q16+Q27 test both sides. |
| **Sheet ratio vs area ratio** | Side ratio = √2:1 ⭐; AREA ratio of consecutive sizes = 2:1 ⭐ (Q15 vs Q52 — read which is asked!). |
| **B2 board vs D3 board** | Boards carry two designation systems: B0–B3 (old) = D0–D3 (IS 1444). B2 = D2 = 700×500×15. PSC keyed D3 = 500×350×15 (Q26) and B2 = 700×500×15 (Q21). |
| **Interior vs exterior angle of pentagon** | Interior = 108° ⭐; exterior/central = 72°. Q45 offered only 72° → X. Q55: construction triangle = vertex 108°, base 36°. |
| **Scale direction** | 1:2 means drawing is HALF: 10 mm drawn = 20 mm actual (Q8). 10 cm drawn for 5 cm object = 2:1 ENLARGING (Q48). Always ask "which is bigger?" |
| Top view above front view | = THIRD angle projection (Q2 intent; first angle: top view BELOW front view). |
| Point behind VP | Top view goes ABOVE xy (Q41); above HP + behind VP = 2nd quadrant (Q54). |
| Pencil for construction/dimension lines | PSC key: **2H** (Q13) — not H, not HB. |
| Sub-title lettering height | PSC key: **6–8 mm** (Q14). Main titles bigger; notes/dimensions 3–5 mm. |
