# 06 — Drawing Instruments, Threads & Fits

*6 of 55 Qs (incl. 1 X). Small mixed bag — instruments plus two machine-drawing strays.*

## 6.1 Instruments — ⭐ asked 3× (+1 X)

- ⭐ **Vernier bevel protractor least count = 5′** (Q3) (main scale 1°, vernier reads 5 minutes).
- ⭐ **Erasing shield** = erases a spot of a line WITHOUT touching adjacent lines (Q6).
- ⭐ **Protractor** = measures/draws angles (Q9) (mini-drafter does lines+angles+scales combined; pro-circle draws circles 🎯).
- (Q30 X) intent: **T-square is used for drawing HORIZONTAL lines** 🎯 — with set squares on it: vertical + 30/45/60° lines. Re-askable clean.

## 6.2 Threads & Fits (machine drawing strays) — ⭐ asked 2×

- ⭐ **M20: M = METRIC thread** (Q7); 20 = nominal (major) diameter mm.
- ⭐ **Fit designation: hole first with CAPITAL letter, then shaft lowercase — 50 H8/g7 correct; "50 g7/H8" is WRONG** (Q47 keyed B as the not-correct form).
  - 🎯 Hole-basis system (H hole) is standard; H8/g7 example fits: clearance. Forms 50 H8/g7, 50 H8-g7, and fraction form all acceptable per SP 46.

## 6.3 🎯 High-Probability Variations

- "Set squares angles" → 45°×45°×90° and 30°×60°×90°.
- "French curves are used for ___" → irregular/non-circular curves.
- "Clinograph" → adjustable set square.
- "Compass vs divider" → compass draws circles; divider transfers/ measures distances.
- "Left-hand thread designation" → LH suffix.
- "Types of fits" → clearance, interference, transition.
