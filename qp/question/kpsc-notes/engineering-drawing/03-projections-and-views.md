# 03 — Projections & Views

*9 of 55 Qs (incl. 1 X). Orthographic basics, quadrants, isometric.*

## 3.1 Orthographic Projection — ⭐ asked 3×

- ⭐ **Projectors parallel to each other AND perpendicular to plane of projection = ORTHOGRAPHIC projection** (Q10).
- ⭐ **Projection on the VERTICAL plane = FRONT view (elevation)** (Q31); on HP = top view (plan) 🎯.
- ⭐ **Horizontally sliced building viewed from top = PLAN** (Q50) (vertical slice viewed horizontally = section/sectional elevation 🎯).
- (Q2, X) intent: **top view ABOVE front view = THIRD angle projection** 🎯 — first angle: top view BELOW front view, object between observer and plane. India/BIS default = first angle. Re-askable clean.

## 3.2 Quadrants & Points — ⭐ asked 2×

| Quadrant | Position |
|----------|----------|
| I | above HP, in front of VP |
| **II** | **above HP, behind VP** ⭐ (Q54) |
| III | below HP, behind VP |
| IV | below HP, in front of VP |

- ⭐ 🧮 Q41: point 20 mm BELOW HP, 30 mm BEHIND VP (3rd quadrant) → **top view = 30 mm ABOVE xy**.
  Rules: front view distance from xy = distance from HP; top view distance from xy = distance from VP. Behind VP → top view above xy; below HP → front view below xy.
- ⚠️ TRAP: stem asks about the TOP view → use the VP distance (30), not 20.

## 3.3 Isometric — ⭐ asked 2×

- ⭐ **Isometric length / true length ≈ 0.815** (Q16) (= cos45°/cos30° = 0.8165 ≈ 0.82).
- ⭐ **Drawn with ACTUAL (true) dimensions, no isometric scale = isometric VIEW** (Q27); with isometric scale = isometric PROJECTION.
- ⚠️ TRAP: view vs projection is THE isometric trap — both directions asked.
- 🎯 Isometric axes at 120° to each other; 30° to horizontal.

## 3.4 Geometry Dimensionality — ⭐ asked

- ⭐ **Solid geometry deals with THREE dimensions** (Q43); plane geometry = 2D.

## 3.5 🎯 High-Probability Variations

- "Symbol of first angle projection" (frustum of cone, big end toward viewer... know both symbols).
- "In first angle projection the object lies between ___" → observer and plane.
- "Side view is projected on ___" → profile plane.
- "Axonometric projections include ___" → isometric, dimetric, trimetric.
- "Angle between isometric axes" → 120°.
