# 02 — Lines, Lettering & Dimensioning

*10 of 55 Qs. Standards-recall territory: IS codes, ratios, mm heights.*

## 2.1 Line Work & Pencils — ⭐ asked 2×

- ⭐ **Pencil for construction lines, dimension lines, centre lines, section lines = 2H** (Q13 PSC key).
  - 🎯 Ladder: 3H–4H light construction (some books), 2H thin lines, H/HB outlines, HB lettering & arrows.
- ⭐ **Chain line (centre line) long:short dash ratio = 6:1 to 4:1** (Q4 PSC key).
- 🎯 Line types likely next: continuous thick = visible outline; continuous thin = dimension/extension/hatching; dashed = hidden; chain thin = centre line; chain thick at ends/changes = cutting plane; ruled + zigzag = break line.

## 2.2 Lettering — ⭐ asked 4×

- ⭐ **Single-stroke lettering IS code = IS 9609** (Q11 — keyed "IS 9609-83").
- ⭐ **Lettering TYPE A: height of capital divided into 14 equal parts** (Q29); line thickness = h/14.
  - 🎯 Type B: 10 parts (thickness h/10). B is more common; A is the '14' answer.
- ⭐ **Size of a letter is described by its HEIGHT** 🔁2× (Q42, Q51) — free mark, asked twice.
- ⭐ **Sub-titles / headings lettering height = 6–8 mm** (Q14 PSC key).
  - 🎯 Ladder: main titles 10–12 (some keys 6–8), sub-titles 6–8, notes/dimensions 3–5 mm.
- 🎯 Standard heights series: 2.5, 3.5, 5, 7, 10, 14, 20 mm (ratio √2).

## 2.3 Dimensioning — ⭐ asked 3×

- ⭐ **Parallel dimensioning** = dimensions from a COMMON feature/datum (Q1 — keyed parallel; shown to right and left of the common feature).
  - 🎯 Family: chain (in series), parallel (common datum), combined (both), coordinate (table of x,y).
- ⭐ **Arrowhead: width = 1/3 of length** (Q23) ↔ ⭐ **length = 3 × width** (Q53) — same fact asked both directions 🔁.
  - 🎯 Arrowhead length ≈ 3 mm; filled type preferred.
- 🎯 Likely next: aligned vs unidirectional dimensioning systems; dimension line never crossed; leader line at 30°–60°.

## 2.4 🎯 High-Probability Variations

- "IS code for general engineering drawing practice" → IS 10714 / SP 46.
- "Hidden lines are drawn as ___" → short dashes.
- "Cutting plane line" identification.
- "Height of lettering for dimensions" → 3–5 mm.
- "Ratio of thickness to height, Type B lettering" → 1:10.
