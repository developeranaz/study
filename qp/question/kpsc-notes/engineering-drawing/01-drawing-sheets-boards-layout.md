# 01 — Drawing Sheets, Boards & Sheet Layout

*15 of 55 Qs — THE biggest ED topic. One table = 27% of ED marks.*

## 1.1 A-Series Trimmed Sheet Sizes — ⭐ asked 6×

Per **IS 10711:2001** ⭐ (Q19 — trimmed drawing sheets code).

| Size | mm | Memory hook |
|------|----|-------------|
| A0 | 841 × 1189 | area = **1 m²** ⭐ (Q25) |
| A1 | **594 × 841** ⭐ (Q33) | half of A0 |
| A2 | **420 × 594** ⭐🔁2× (Q5, Q40) | area = **0.25 m²** ⭐ (Q18) |
| A3 | 297 × 420 | |
| A4 | 210 × 297 | notebook size |

- ⭐ **Length : width = √2 : 1** (Q15) — i.e. $2^{1/2}:1$.
- ⭐ **Areas of two subsequent sizes are in ratio 2:1** (Q52 — keyed 1:2, smaller:larger). Each size = previous halved along long side.
- ⚠️ TRAP: Q15 asks SIDE ratio (√2:1); Q52 asks AREA ratio (1:2). Don't mix.
- 🎯 Untrimmed sizes are ~larger (A0 untrimmed 880×1230); "trimmed" = final standard size.

## 1.2 Drawing Boards — ⭐ asked 3×

Two designation systems appear in PSC papers — **B-series and D-series are the same boards** (IS 1444 uses D0–D3):

| Designation | Size (mm) | For sheet |
|------------|-----------|-----------|
| B0 / D0 | **1500 × 1000 × 25** ⭐ (Q20) | A0 |
| B1 / D1 | 1000 × 700 × 25 | A1 |
| B2 / D2 | **700 × 500 × 15** ⭐ (Q21) | A2 |
| B3 / D3 | **500 × 350 × 15** ⭐ (Q26) | A3/A4 |

- Memory hook: thickness 25 mm for the two big boards, 15 mm for the two small.
- ⭐ **Preferable slope of drawing board support = 1:6** (Q24).
- 🎯 Board material: well-seasoned soft wood (pine); working edge = ebony strip.

## 1.3 Sheet Layout — ⭐ asked 2×

- ⭐ **Title block: RIGHT BOTTOM corner** (Q22); standard size 185 × 65 mm 🎯 (same for all sheet sizes).
- ⭐ **Minimum border on left of A0/A1 = 20 mm** (Q32) (filing/binding margin; other edges A0/A1 = 20 mm, A2–A4 left 20 mm, others 10 mm 🎯).
- 🎯 Title block contains: name, title, scale, date, drawing number, projection symbol.

## 1.4 Sheet Folding — ⭐ asked

- ⭐ **Folding method 1: final folded size 297 × 190 mm** (Q28).
- 🎯 Method 2 (folder filing): 297 × 210 mm (A4). Larger sheets folded so title block shows on top.

## 1.5 🎯 High-Probability Variations

- "Size of A4 / A3 / A0 sheet" — any row of the table.
- "Which sheet has area 0.5 m²?" → A1.
- "Designation of board for A1 sheet" → B1/D1 (1000×700×25).
- "Untrimmed vs trimmed" definition.
- "Ebony edge of drawing board is used for..." → T-square stock sliding.
