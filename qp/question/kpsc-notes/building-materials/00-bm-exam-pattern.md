## Signature KPSC habits in this subject

1. **Numbers over concepts.** Most Qs are pure figures: 50–60% silica, 50 kg bag, 0.034/0.035 m³, 1440 kg/m³, 1400 °C, 3.5 N/mm², 19×9×9 cm, 10–12% moisture. Make a numbers flash-list (each file ends with one).
2. **Rock classification is a guaranteed question.** "Which is sedimentary?" appeared 3× (limestone every time). Marble = metamorphic appeared 2×.
3. **Same fact re-asked with tiny wording change.** Max coarse-aggregate size for RCC = 20 mm asked twice (Q7, Q29). Cement-bag volume asked twice with different decimals (0.034 vs 0.035 m³) — both accepted ⚠️.
4. **Obscure IS-code numbers appear** (super sulphated cement IS 6909, oil-well cement IS 8229). Low yield per effort — memorize only the ones already asked.
5. **X-questions still signal topics**: low-heat cement composition (C₃S/C₃A limits), C₃S early strength, cement for marine works (sulphate-resisting), curing temperature 27 ± 2 °C, annual rings, admixture types (lignin/sugars/polycarboxylates = retarders/plasticizers). Expect clean versions of these next time 🎯.
