# 06 — Trigonometry

*4 of 53 Qs. Identities + one height-and-distance numerical.*

## 6.1 Identities — ⭐ asked 2×

- ⭐ **1 + tan²θ = sec²θ** (Q39).
  🎯 Family: sin²+cos² = 1; 1+cot² = cosec². (Memory: tan→sec, cot→cosec.)
- ⭐ **cot(90°+θ) = −tanθ** (Q40).
  ⚠️ 90°±θ swaps the function (tan↔cot, sin↔cos, sec↔cosec); sign from quadrant:
  90+θ is Q2 → only sin/cosec positive → cot negative → **−tanθ**.
  🎯 180°±θ keeps the function, sign from quadrant (ASTC: All-Sin-Tan-Cos).

## 6.2 🧮 Heights & Distances — ⭐ asked

- Q44: pole 20 m, shadow 20√3 m → tanθ = 20/(20√3) = 1/√3 → **θ = 30°**.
- Template: tan(elevation) = height ÷ shadow. Memorise:
  | tanθ | θ |
  |------|---|
  | 1/√3 | 30° |
  | 1 | 45° (shadow = height) |
  | √3 | 60° |
