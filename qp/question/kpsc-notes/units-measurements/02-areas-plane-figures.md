# 02 — Areas of Plane Figures

*13 of 53 Qs. School mensuration — every numerical is calculator-free by design.*

## 2.1 Formula Sheet — ⭐ all asked

| Figure | Area |
|--------|------|
| Triangle | ½ × base × height |
| Heron's | √(s(s−a)(s−b)(s−c)), s = semi-perimeter |
| **Equilateral triangle** | **(√3/4)s²** ⭐ (Q21) |
| **Trapezium** | **½(a+b)×h** ⭐ (Q36) |
| Rhombus | **½ d₁d₂** (Q18 X — options corrupted, formula is the intent) |
| Circle | πr²; perimeter 2πr |
| Parallelogram | base × height 🎯 |

## 2.2 🧮 Worked PSC Numericals (all clean numbers)

1. Q9: square with same area as 50×25 mm rectangle → side = √1250 = **35.36 mm**.
2. Q10: right triangle base 15, HYPOTENUSE 21 → height = √(21²−15²) = √216 = 14.7 → area = ½×15×14.7 = **110.18 cm²**. ⚠️ TRAP: 21 is the hypotenuse, not the height.
3. Q12: circle area 154 cm² → r² = 154×7/22 = 49, r=7 → perimeter = 2×22/7×7 = **44 cm**. (154 and 616 are the classic 22/7-friendly areas.)
4. Q13: rectangle 90×40 = 3600 → square **60×60, perimeter 240 m**. ⚠️ bait: option B has right side, wrong perimeter (360).
5. Q16: isosceles triangle A=1000 mm², base 100 → h = 2A/b = **20 mm**.
6. Q17: sides 3-4-5 → right triangle → ½×3×4 = **6 cm²** (Heron's gives same).
7. Q19: perimeter 14, l = w+1 → l+w = 7 → 4×3 → area = **12 cm²**.
8. Q24: square "circumference" (perimeter) 16 → side 4 → area = **16 cm²** (perimeter = area number coincidence).
9. Q27: rod 86 cm bent to rectangle, l = b+7 → l+b = 43 → l = **25 cm**.
10. Q32: square area 625 → side 25 → perimeter = **100**.

## 2.3 Solving Templates

- Perimeter given + relation between l and b → l+b = P/2, solve linear pair.
- Area given, find perimeter (or reverse) → extract side/radius first.
- 3-4-5, 5-12-13, 8-15-17 triples: KPSC scales these (15-?-21 in Q10 wasn't a triple — computed √216).

## 2.4 🎯 High-Probability Variations

- Area of sector = (θ/360)πr²; arc length = (θ/360)2πr.
- Circle: area 616 → r = 14 → circumference 88.
- Annulus (ring) area = π(R²−r²).
- Diagonal of square = s√2; of rectangle = √(l²+b²).
- Cost-type wrapping: "fencing at ₹x per metre" → perimeter × x.
