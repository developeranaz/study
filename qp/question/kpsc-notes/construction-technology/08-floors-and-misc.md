*Small catch-all: 3 direct Qs + concept neighbourhoods PSC dips into.*

## 8.1 Floors — ⭐ asked

- ⭐ **Dancing halls / auditoriums → WOODEN (timber) floor** (Q13) — resilience/springiness. (Distractors: granolithic, terrazzo, mosaic.)
- ⭐ **Double joist timber floor: suitable span 3.6–7.5 m** (Q12) — binders + bridging joists.
  Ladder 🎯: single joist ≤ 3.6 m; **double 3.6–7.5 m** ⭐; framed/triple (girders+binders+joists) > 7.5 m.
- Ground floor types & uses 🎯:
  | Floor | Use |
  |-------|-----|
  | Mud/moorum | cheap village |
  | Brick / flagstone | godowns, cheap |
  | Cement concrete (conglomerate) | most common residential |
  | **Granolithic** | wearing topping over concrete — factories ⚠️ distractor |
  | **Terrazzo** | marble chips + cement, polished — hotels, hospitals ⚠️ |
  | **Mosaic** | small tile/marble pieces in patterns ⚠️ |
  | Marble | operation theatres (joint-free, clean) 🎯 |
  | Asphalt/mastic | dust-free, acid-resistant industrial 🎯 |
  | Rubber/PVC/linoleum | noiseless — libraries, offices 🎯 |
  | Cork | noiseless best — libraries/theatres 🎯 |
- Flooring layers: base concrete + wearing course; laid in alternate bays to control shrinkage 🎯.

## 8.4 Damp-Proofing / Plastering Neighbourhood 🎯

(No direct CT Qs this bank, but adjacent — cheap insurance:)
- DPC: bitumen felt/mastic/cement concrete 1:2:4 with waterproofer; horizontal DPC at plinth, full wall width, not across doorways.
- Causes of dampness: rising capillary moisture, rain penetration, condensation.
- Plaster thickness: single coat 12 mm, two-coat 18–20 mm; ceiling 6 mm; curing 7 days.
- Defects: blistering, cracking, efflorescence, flaking, peeling, popping.
