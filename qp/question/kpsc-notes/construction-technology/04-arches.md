## 4.1 Arch Terminology — ⭐ the asked set

| Term | Meaning |
|------|---------|
| **Intrados** | **Inner CURVE of arch** ⭐ (Q20) |
| **Soffit** | **Inner/under SURFACE of arch** ⭐ (Q25) ⚠️ TRAP: "curve"→intrados, "surface"→soffit — PSC asked both and the options contained both! |
| Extrados | Outer curve of arch |
| Voussoirs | Wedge-shaped arch units ⚠️ frequent distractor |
| Key stone | Highest central voussoir |
| Springer / springing line | Lowest voussoir / line where arch springs from support |
| Skewback | Inclined support surface (flat arches & segmental) — ⭐ **in flat arch, skewback makes 60° with springing line** (Q22) (i.e., 30° with horizontal per some books — PSC key: 60° with springing line) |
| Crown | Highest part of extrados |
| Haunch | Lower half of arch between crown & skewback ⚠️ distractor |
| **Spandril** | **Irregular triangular walling between extrados, horizontal line from crown & vertical from springing** ⭐ (Q38) |
| Abutment / pier | End support / intermediate support 🎯 |
| Rise, span | Vertical height crown-to-springing line; clear distance between supports 🎯 |
| Depth/height of arch | Perpendicular distance intrados↔extrados 🎯 |

## 4.2 Types of Arches — ⭐ asked

| Type | Feature |
|------|---------|
| Flat/straight arch | Camber ~10–15 mm/m; intrados apparently level; **skewback 60°** ⭐ |
| Segmental | Circular arc < semicircle; thrust inclined 🎯 |
| Semicircular | Centre on springing line; vertical thrust 🎯 |
| Horse-shoe | More than semicircle (Moorish) 🎯 |
| **Pointed (Gothic)** | **Two curves MEETING AT APEX of triangle** ⭐ (Q21) — equilateral/lancet/drop variants 🎯 |
| Relieving arch | Above flat arch/wooden lintel to relieve load 🎯 likely |
| **Venetian** | **FOUR-centred arch** ⭐ (Q14) — deeper crown |
| **Florentine** | Also four-centred style but intrados semicircular... ⚠️ PSC key for "four-centred example" = **Venetian**; Florentine was the distractor. Remember: Venetian = 4 centres; Tudor = 4 centres; Florentine = 3 centres. |
| Three-centred / five-centred / elliptical | know the counts 🎯: semi-elliptical made with 3 or 5 centres |
| Stilted | Semicircle + vertical portions 🎯 |

**Centre-count cheat line 🎯:** one-centre = segmental/semicircular/horse-shoe/stilted; two-centre = pointed/blunt; three-centre = elliptical/Florentine; four-centre = Venetian/Tudor.

## 4.3 By Material/Workmanship 🎯

- Stone arch: rubble (inferior, <1 m spans) / ashlar.
- Brick arch: rough (rectangular bricks, wedge joints — inferior), axed (cut wedge bricks), gauged (soft rubber bricks, lime-putty joints — finest), purpose-made.
- Gauged brick arch → best finish; joints 1–1.5 mm. 🎯

## 4.4 Construction Notes 🎯

- Arches transfer load by COMPRESSION to abutments (no tension ideally).
- Centering (temporary formwork) removed after key stone set.
- Failure modes: crushing, sliding, rotation of voussoir, uneven abutment settlement.

## 4.5 🎯 High-Probability Variations

- "The wedge-shaped units of an arch are called" → voussoirs.
- "Highest central voussoir" → key stone; "arch springs from" → springing line.
- Camber of flat arch intrados (~10–15 mm per metre).
- Depth of flat arch ≈ 1/12 span; segmental rise ≈ 1/6–1/10 span.
- Lintel vs arch: lintel = horizontal bending member; arch = compression (see file 06 for lintels).
