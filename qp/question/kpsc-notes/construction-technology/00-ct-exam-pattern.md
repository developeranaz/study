## Question Style

- **~90% single-fact recall**: term definitions ("inner curve of arch = intrados") and NUMBER facts (minimum areas, spans, percentages, dimensions). Only ONE numerical in the whole set (riser/tread count) and one statement-evaluation question.
- **Number-heavy**: 24 of 66 questions ask for a specific dimension/percentage/span. CT is essentially a "memorize the numbers tables" subject.
- **Terminology matching**: parts of stairs/arches/roofs/doors — PSC gives 4 component names and asks which is which.
- **Kerala flavour**: bye-law questions follow **Kerala Municipality Building Rules (KMBR) / NBC** — setbacks, coverage %, room areas, building height vs street width. Other state PSCs rarely ask this many.

## The Trap Catalogue (CT-specific)

| Trap | Resolution |
|------|-----------|
| **Corbel vs cornice vs coping** | Corbel = projection SUPPORTING something (wall plate) ⭐. Cornice = decorative projection. Coping = protective top course of wall. |
| **Intrados vs soffit** | Intrados = inner CURVE (line) of arch ⭐; Soffit = inner (under) SURFACE ⭐. PSC asked BOTH — "curve"→intrados, "surface"→soffit. Read the stem word! |
| **English vs Flemish bond** | English = headers and stretchers in ALTERNATE COURSES ⭐; Flemish = alternate IN THE SAME COURSE ⭐. Both asked. |
| **Racking back vs toothing** | Racking back = stepped termination of wall ⭐; toothing = alternate projecting bricks for future extension. |
| **Shoring vs underpinning vs scaffolding** | Shoring = TEMPORARY support of unsafe structure ⭐🔁2×; Underpinning = strengthening/replacing FOUNDATION of existing building ⭐🔁2×; Scaffolding = temporary platform for workmen. |
| **String vs flight vs soffit (stairs)** | String = inclined member supporting step ends ⭐; Flight = series of steps between landings ⭐; Soffit = under-surface of stair ⭐. All three asked. |
| **Stile vs rail vs mullion vs transom** | Stile = VERTICAL side member of shutter ⭐; Rail = horizontal member; Mullion = vertical division of window; Transom = horizontal division. |
| **Winders** | GOOD staircase AVOIDS winders ⭐ (Q34's wrong statement said "should not be avoided"). |
